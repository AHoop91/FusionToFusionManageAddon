Set up Fusion Manage

Sign-in needs an app of your own on the Autodesk Platform Services (APS) portal. Follow these steps once.

A Hub Admin may have saved this hub's setup already.

  1. 1
    Create an APS app

    Create it on the APS portal with the settings below.

    Application TypeDesktop, Mobile, Single-Page Web App
    Grant TypeAuthorization Code with PKCE
    API AccessManufacturing Data Model APIIdentity API
  2. 2
    Add the callback URL

    On your app's page, add this as a Callback URL, and save the app.

  3. 3
    Enter the Client ID

    Copy it from your app's page on the APS portal.

  4. 4
    Sign in

    Saves the Client ID and opens the Autodesk sign-in in your browser.
