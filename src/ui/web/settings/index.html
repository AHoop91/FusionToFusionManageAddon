Set up Fusion Manage

Is this hub already set up, or is this the first time? Choose how to start.

Another Hub Admin has already set this hub up and saved the setup as a Configuration File in the Fusion Hub. Choose that file to use the same setup. You do not need an APS app of your own or to enter a tenant.

Sign-in needs an app of your own on the Autodesk Platform Services (APS) portal. Follow these steps once.

  1. 1
    Create an APS app

    Create it on the APS portal with the settings below.

    Application TypeDesktop, Mobile, Single-Page Web App
    Grant TypeAuthorization Code with PKCE
    API AccessManufacturing Data Model APIIdentity API
  2. 2
    Add the callback URL

    On your app's page, add this as a Callback URL, and save the app.

  3. 3
    Enter the Client ID

    Copy it from your app's page on the APS portal.

  4. 4
    Sign in

    Saves the Client ID and opens the Autodesk sign-in in your browser.

  5. 5
    Allow the app in Fusion Manage

    A Fusion Manage administrator adds the Client ID in System Configuration, General Settings on your tenant (plm/admin/system-configuration/general-settings). Until then the workspace lists fail with a 401 error.
